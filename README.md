# LIAs and LIMs Imprecise/ Approximate Adders and Multipliers

**C, Python, and Verilog RTL implementations** of the LIA approximate adder and LIM approximate multiplier libraries, with configurable imprecision levels.

Original paper: [A Comprehensive Model for Efficient Design Space Exploration of Imprecise Computational Blocks](https://doi.org/10.1145/3625555).

Website: [llgelarall.github.io/lia-lim](https://llgelarall.github.io/lia-lim/)

Original architectures and C libraries by the ICVLSI research group, Shahid Beheshti University, Tehran. Website, Python/RTL versions, and validation by [Gelara](https://gisink.com/).
